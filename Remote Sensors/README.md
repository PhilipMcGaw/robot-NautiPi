# Remote Sensors

This folder contains retained project material for remote sensor experiments
and prototypes that are separate from the main robot hardware assemblies.

## Contents

- `Beehive/` — retained Beehive sensor project material and photographs.
- `Moisture sensor/` — retained moisture-sensor project material and photographs.

The current contents are primarily historical photographic records. No
current hardware, communications, calibration, or deployment status is implied
by the presence of these files.

## Current status

These projects are retained for reference. They are not currently identified
as active sources of truth for the robot hardware or software architecture.

Where a remote-sensor project is revived, its hardware design, firmware,
interfaces, validation evidence, and licensing should be documented before it
is treated as part of the current Robots system.

## Relationship to the Robots project

Cross-project architecture and engineering context are maintained in
[Chartroom](https://chartroom.philipmcgaw.com/).

The physical hardware record is maintained in [robot-NautiPi](../README.md).
Active robot software is maintained in
[robot-CuttleOS](https://github.com/PhilipMcGaw/robot-CuttleOS), and independent
ROS 2/Gazebo simulation and integration testing are maintained in
[robot-SquidLink](https://github.com/PhilipMcGaw/robot-SquidLink).
