# Mooncrest Models — K9 Components

Catalogue review of Mooncrest Models items that appear to be K9 components or potentially useful K9 reproduction parts.

## High-confidence K9 components

| Item | Confidence | Notes |
|---|---|---|
| Robot Dog Antennas / ears | High | Explicitly described as robot-dog parts; 1:1 scale reproduction. |
| Robot Dog visor | High | Explicitly described as a 1:1 robot-dog visor, made from measurements of an original item. |
| Robot Dog Sensor Eye | High | Explicitly described as a robot-dog component, produced using reference and measurements from original props. |
| Robot Dog Tail Gator | High | Catalogue explicitly identifies this as a Robot Dog part. |
| Robot dog Control panel | High | Explicitly described as a prop addition suitable for robot dogs. |
| 60s style tumbler sets, various colours | High / very strong | Mooncrest describes these as rare “robot monster parts”; supplied as a pair. Potentially a significant K9 reproduction component. |

## Probable K9 components — visual confirmation recommended

| Item | Confidence | Notes |
|---|---|---|
| “Gun” bezels | Probable | Geometry and terminology are consistent with K9 head gun/bezel construction, but Mooncrest does not explicitly identify them as K9 parts. |
| 60s “Toffee Apple” Style Robotic Eye ball | Possible | Robotic eyeball component; Mooncrest does not explicitly identify it as K9. |
| 2005 Toffee Apple style robotic eye ball | Possible | Later version of the robotic-eye component; also not explicitly identified as K9. |

## Items reviewed but not counted as K9 components

- 80s Air freshener part with fixing ring — described as a reproduction of an 1980s car air freshener.
- Fresnel lens MK1, 1:6th scale — generic prop component.
- 1/6th scale “scatter” bricks — generic diorama/prop material.
- Cyber Detail “Bullet” tray — Cyberman-related.
- Other Cyberman, Alien, Liberator, and generic prop components.

The individual product descriptions should be treated as the primary evidence for catalogue classification. “High”, “Probable”, and “Possible” describe the strength of the identification, not a claim that Mooncrest officially markets every item as a K9 component.
