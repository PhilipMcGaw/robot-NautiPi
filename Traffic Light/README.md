# Traffic Light

This folder contains retained historical material from the Traffic Light
project.

## Contents

The current contents are primarily photographs and other retained project
reference material.

## Current status

This is historical project material. It does not represent a current robot
hardware design, software implementation, or validated system component.

No production-validation claim is made here without explicit engineering and
test evidence.

## Relationship to the Robots project

The material is retained in [robot-NautiPi](../README.md) as part of the wider
physical hardware and project archive.

Cross-project architecture and engineering context are maintained in
[Chartroom](https://chartroom.philipmcgaw.com/). Active robot software is
maintained in [robot-CuttleOS](https://github.com/PhilipMcGaw/robot-CuttleOS),
and independent ROS 2/Gazebo simulation and integration testing are maintained
in [robot-SquidLink](https://github.com/PhilipMcGaw/robot-SquidLink).
