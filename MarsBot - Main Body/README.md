# MarsBot Main Body

This folder contains retained MarsBot main-body project material and the
long-horizon rover-development reference work associated with it.

It is part of [robot-NautiPi](../README.md), which is the physical hardware
and embedded-project repository for the wider Robots project.

## Contents

- `docs/roadmap.md` — long-horizon Mars-rover platform direction and research-derived roadmap candidates.
- `openrover_project_report.pdf` — retained OpenRover project report used as a reference for future development direction.

## Current status

This is retained development and reference material. The roadmap describes
future or exploratory capability and does not establish that the corresponding
hardware, software, autonomy, communications, suspension, steering, or sensing
capabilities have been implemented or validated.

No production-validation claim is made here without explicit engineering and
test evidence.

## Relationship to the Robots project

Cross-project architecture, engineering rationale, and project-wide
roadmapping are maintained in [Chartroom](https://chartroom.philipmcgaw.com/).

The current robot software architecture is maintained in
[robot-CuttleOS](https://github.com/PhilipMcGaw/robot-CuttleOS), while
[robot-SquidLink](https://github.com/PhilipMcGaw/robot-SquidLink) provides the
independent ROS 2/Gazebo simulation and integration-test environment.

MarsBot material in NautiPi should therefore be treated as physical hardware
reference and retained project history rather than as an active software or
simulation source of truth.
