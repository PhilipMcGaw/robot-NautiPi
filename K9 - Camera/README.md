# K9 Camera

This directory contains retained camera setup material for K9, including the `CameraSetup.sh` script and reference videos documenting an earlier Raspberry Pi camera experiment.

## Contents

- `CameraSetup.sh` — retained camera setup script.
- `How To Make A Cheap 360 Video Camera With A Raspberry Pi - Part 1.mp4` — reference video.
- `How To Make A Cheap 360 Video Camera With A Raspberry Pi - Part 2.mp4` — reference video.

## Current status

This directory is reference and historical project material. It does not define the current K9 media architecture or establish that the recorded camera arrangement is the current hardware solution.

The current robot software architecture is maintained in CuttleOS. Current media requirements, including stereo video, recording, audio, and presentation, are defined by the current software architecture and robot profiles rather than by this historical camera experiment.

No statement of current hardware integration, commissioning, or production validation is made by the contents of this directory.
